# Yomuyume

<div align="center">
  <img src="client/public/favicon/android-chrome-192x192.png" alt="Yomuyume logo" width="192" height="192">

Self-hosted media server for manga and comics.

</div>

## highlights

-   ⚡ written in 🦀 Rust for blazingly fast performance,

-   🛡️ no intermediate representation <sup>1</sup>
-   🧠 automatically detect between **oneshots/series titles** and **categories**,
-   🗃️ support all the archive formats thanks to `7zip`,
-   📄 [ComicInfo 2.1](https://anansi-project.github.io/docs/comicinfo/intro) and [OPDS-PSE 1.2](https://anansi-project.github.io/docs/opds-pse/intro) compliance,
-   ⭕ support `.nomedia` files,

> <sup>1</sup> we encourage managing your library at the file system level to avoid vendor lock-in

and many more.
